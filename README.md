One original line roasting the gadget I use every day: my old laptop. Its fan screams like a jet taking off the moment I open a second Chrome tab, then gives up and lets the whole machine slow-cook itself. The program writes that single line to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Set `OUTPUT_DIR` to write somewhere else instead of `/output` (handy for a local test run):

```sh
OUTPUT_DIR=/tmp/roast-test node main.ts
```
